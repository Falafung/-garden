# 🌿 สมุดสวน — เว็บแอปจัดการสวน

เว็บแอปสำหรับบันทึกและดูแลสวน ใช้ได้ทั้งบนคอมพิวเตอร์และมือถือ ไม่ต้องติดตั้งโปรแกรม ไม่ต้องมีเซิร์ฟเวอร์

## ความสามารถ

| เมนู | ทำอะไรได้ |
|---|---|
| **ภาพรวม** | สรุปจำนวนแปลง พื้นที่ จำนวนต้น รายรับ-รายจ่ายเดือนนี้ โอกาสฝนวันนี้ งานที่ต้องทำ และวัสดุใกล้หมด |
| **แปลงปลูก** | ระบุชื่อแปลง พืช สายพันธุ์ เนื้อที่ (ไร่-งาน-ตร.วา) จำนวนต้น ระยะปลูก วันที่ปลูก (คำนวณอายุต้นและความหนาแน่นต่อไร่ให้) |
| **ปฏิทินงาน** | ปฏิทินรายเดือน บันทึกว่าแต่ละวันทำอะไรกับแปลงไหน (รดน้ำ ใส่ปุ๋ย พ่นยา ฯลฯ) และวางแผนงานล่วงหน้าพร้อมติ๊กเมื่อทำเสร็จ |
| **ลมฝน** | โอกาสฝนวันนี้ ปริมาณฝน ความเร็ว/ทิศลม กราฟโอกาสฝนรายชั่วโมง พยากรณ์ 7 วัน และคำแนะนำ เช่น ควรพ่นยาไหม งดรดน้ำได้ไหม |
| **ผลผลิต** | บันทึกผลผลิตแต่ละครั้ง ปริมาณ เกรด ราคา สรุปผลผลิตต่อแปลงและต่อต้น ลงบัญชีรายรับให้อัตโนมัติ |
| **บัญชี** | รายรับ-รายจ่ายแยกหมวดและแยกแปลง กำไร/ขาดทุน กราฟ 12 เดือน ส่งออกเป็น CSV เปิดใน Excel ได้ |
| **คลังวัสดุ** | ยอดคงเหลือของปุ๋ย ยา และอุปกรณ์ ตัดยอดอัตโนมัติเมื่อบันทึกงานที่ใช้วัสดุ และเตือนเมื่อใกล้หมด |
| **คลังความรู้** | บันทึกความรู้ เช่น ปุ๋ยแต่ละสูตรช่วยด้านไหน วิธีใช้ โรคและแมลง มีข้อมูลตั้งต้นให้ เพิ่มหรือแก้เองได้ |
| **ตั้งค่า** | ชื่อสวน ธีมสว่าง/มืด สำรองและนำเข้าข้อมูล ข้อมูลตัวอย่างสำหรับทดลองใช้ |

## วิธีใช้

- **เปิดในเครื่อง:** ดาวน์โหลดโฟลเดอร์นี้ แล้วดับเบิลคลิก `index.html`
- **ใช้ผ่านเว็บ/มือถือ:** เปิด GitHub Pages ของ repo นี้ (Settings → Pages → Deploy from branch) แล้วเปิดลิงก์ในมือถือ และกด “เพิ่มไปยังหน้าจอหลัก”
- ครั้งแรกให้ไปที่เมนู **ลมฝน** เพื่อตั้งตำแหน่งสวน (กดใช้ตำแหน่งปัจจุบัน หรือค้นหาชื่ออำเภอ/จังหวัด)

## ข้อมูลเก็บที่ไหน

ข้อมูลทั้งหมดเก็บไว้ใน**เบราว์เซอร์ของเครื่องที่ใช้งาน** (localStorage) ไม่ได้ส่งขึ้นเซิร์ฟเวอร์ใด
- ถ้าล้างข้อมูลเบราว์เซอร์ ข้อมูลจะหาย จึงควรกด **ตั้งค่า → ส่งออกข้อมูล** เก็บไว้เป็นระยะ
- ถ้าจะย้ายไปใช้เครื่องอื่น ให้ส่งออกไฟล์ `.json` แล้วกด **นำเข้า** ที่เครื่องใหม่

ข้อมูลพยากรณ์อากาศมาจาก [Open-Meteo](https://open-meteo.com/) ซึ่งใช้ฟรีและไม่ต้องสมัคร API key

## ไฟล์

- `index.html` — โครงหน้าเว็บ
- `style.css` — หน้าตา (รองรับมือถือและโหมดมืด)
- `app.js` — การทำงานทั้งหมด
